# Shubham Kumar — Portfolio Website

Personal portfolio website for **Shubham Kumar**, Senior .NET & Azure Backend Engineer with 8+ years of experience building scalable enterprise applications, microservices, and cloud-native solutions.

🔗 **Live:** *(update once deployed)*

---

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | Next.js 16 (App Router) |
| Language | TypeScript |
| Styling | Tailwind CSS v4 |
| Animations | Framer Motion |
| Deployment | Vercel |

## Sections

- **Hero** — Introduction, CTA, and social links
- **About** — Career narrative and highlights
- **Skills** — Tech grouped by category (Backend, Cloud, DB, Frontend, Architecture, AI Tools)
- **Experience** — Career timeline
- **Projects** — 6 featured GitHub projects
- **Achievements** — Key stats
- **Blog** — Latest Medium articles
- **Testimonials** — Quotes from colleagues
- **Contact** — Form + social links

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Updating Content

All portfolio content (experience, projects, blogs, skills, etc.) is managed from a single file:

```
src/lib/data.ts
```

Update your social links, company names, and project details there.

## Deploying

The easiest way to deploy is via [Vercel](https://vercel.com):

1. Push this repo to GitHub
2. Import it on vercel.com
3. Vercel auto-detects Next.js — click **Deploy**
